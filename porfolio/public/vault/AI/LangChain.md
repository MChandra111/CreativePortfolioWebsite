
LangChain is an open-source framework that simplifies building any application that uses an LLM.

It helps developers connect LLMs with external data, tools, and workflows.

### **Major Components**

1) Memory Management - Maintain context
2) Models - Multiple LLMs
3) Chains - Define sequence of steps, each one uses an LLM or [[Tool Call]]
4) Vector Databases - Stores data as vectors for [[Similarity Search]]
5) Prompt Management - Helps design & manage prompts using templates
6) Agents - LLM driven components that decide on actions and take them
---

### **How does LangChain work**

LangChain enables [[Retrieval-Augmented Generation (RAG)]] by combining document processing, vector storage, and LLMs. It connects [[Embeddings]], [[Vector Databases]], and models into a smooth workflow.
