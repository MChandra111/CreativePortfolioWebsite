
A Multi-Agent System (MAS) is a network of multiple autonomous [[AI]] agents that communicate and work with each other to achieve individual or collective goals.

![[Pasted image 20260530232300.png]]
### **Core elements**
- Agents
- Environment (The shared space)
- Interactions - Communication, Cooperation, Competition
- Coordination - Minimum conflict

Specifically recommended when tasks require **parallel work**, specialized tools, large [[Context]], or multiple decision checkpoints.

A single agent lifecycle is simply: Perceive -> Reason -> Act.
A Multi-Agent System uses [[Agent Loops]] on top of adding Coordinate and Communicate onto the end.
