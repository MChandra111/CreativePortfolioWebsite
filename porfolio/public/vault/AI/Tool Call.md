
Encompasses **Function Calling**. Though, Function Calling refers to an LLM's ability to generate structured outputs that describe a specific function invocation.

A Tool Call is performed by an LLM to request relevant data or perform an action that is separate from its chatbot capabilities. There are several components involved in tool calling

1) The model itself - It has to recognize it lacks sufficient knowledge or requires an external function to complete a request
2) Tool selection mechanism - It must identify the appropriate dependencies to handle the task at hand
3) API Interface - Allows the [[AI]] to send structured queries and receive responses in a format that it can read
4) Response processing system - Helps ensure the retrieved data is formatted correctly and presented to the user in a meaningful way


**4 Common Categories**
1) Information Retrieval - Fetching real-time data
2) Code Execution - Run scripts or complex calculations
3) Process Automation - AI automates workflows, used in [[Agentic AI]] or [[Multi-Agent Systems]]
4) Smart Devices & IoT Monitoring - [[Agentic AI]] systems can monitor and control home automation systems, industrial IoT devices, and robotics.
