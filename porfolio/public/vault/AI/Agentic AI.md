
Agentic AI is a form of [[AI]]

Agentic AI has **autonomy**. Rather than simply responding to a human ask, it uses multiple tools at its disposal to ==achieve a task==.

"How Agentic" something is is ranked on a scale from 1 to 36. An AI assistant that can search the web is "agentic" the same way that a full sales pipeline agent that can run without supervision is "agentic". It's a buzzword at the surface level.

A true Agentic AI has to be able to:
- Receive a task ("Create this app")
- Decides what tool to use
- Use its tools (Call an API, edit a file, navigate a browser)
- Observe the result
- Decide again

These are known as [[Agent Loops]]

There are **6** **properties** that make a system "agentic". The higher the tool ranks, the more autonomous it is.
- Goal-directed
	- Takes an outcome, not an instruction, and figures out the steps on its own
- Plans multi-step work
- Takes real action
	- *Does things* rather than just suggest
- Adapts on the fly
- Maintains state
	- Carries [[Context]] across steps and sessions instead of starting from scratch.
- Knows when to stop

There are **8 dimensions** of "Agentic-ness". Each of these is rated 0-4 to determine "how agentic" something is.
- Action Capability
- Autonomy
- Planning & Reasoning
- Adaptation & Recovery
- State & Continuity
- Reliability
- Interoperability
- Safety & Observability

And there are then mapped to **6 subsequent levels** based on their scores. Higher isn't better, it depends on what the agent actually *needs to do*.

| L0  | Reactive Tool         | 0-5   |
| --- | --------------------- | ----- |
| L1  | Guided Assistant      | 6-11  |
| L2  | Adaptive Collaborator | 12-17 |
| L3  | Domain Specailist     | 18-23 |
| L4  | Autonomous Operator   | 24-28 |
| L5  | Strategic Agent       | 29-32 |
