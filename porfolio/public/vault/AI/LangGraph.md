
[LangGraph](https://www.langchain.com/langgraph)

LangGraph is an open-source [[Agent Orchestration]] framework.

Fundamentally allows you to organize [[Agentic AI]] workflows using graph-based architecture for easier readability and buildability.

Allows for multiagent workflows and allows for parallel processing.

Supports simple use cases like chatbots as well as [[Multi-Agent Systems]]

Integrates LLMs with external tools, APIs, and memory.
### **Features**

 1) Granular Control
 2) Built-in memory capabilities to store conversation histories, enable context-aware interactions, etc.
 3) Token-by-token streaming, real-time insights into agent reasoning & actions
 4) Used for human-in-the-loop workflows, where human oversight can steer or approve agent actions.
 5) Quality control mechanisms to prevent agents from veering off course.
