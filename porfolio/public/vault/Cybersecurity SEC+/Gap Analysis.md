**Where you are** -> **Where you want to be**
Can take weeks to years to compile all the information required

**Process**:
### **Choosing the framework**

Work towards a known baseline
- This may be an internal set of goals
- Some orgs use formal standards
- NIST/ISO standards
### **Evaluate people and processes**

Get a baseline of employees
- Formal experience
- Current training
- Knowledge of security policies & procedures

Examine the current processes
- Research existing IT systems
- Evaluate existing security policies
### **Compare and Contrast**

The comparison
- Evaluate existing systems

Identify weaknesses
- Along with the most effective processes

A detailed analysis
- Examine broad security categories
- Break those into smaller segments
### **Analysis and report**

The final comparison
- Detailed baseline objectives
- A clear view of the current state

Need a path
- Will include time, money, and lots of change control

Create Gap Analysis Report
- Formal description of the current state
- Recommendations for meeting the baseline
